# Active Directory Home Lab

## Overview

Built a virtual company network to practice Windows system administration and cybersecurity concepts in an isolated lab environment.

## Technologies

- Windows Server
- Windows 11
- Active Directory Domain Services
- DNS
- Group Policy
- VirtualBox

## What I Built

- Configured a Windows Server domain controller
- Created an Active Directory domain
- Joined a Windows client computer to the domain
- Created and organized users and groups
- Configured Group Policy settings
- Implemented password and account lockout policies
- Configured DNS for the Active Directory environment

## Skills Demonstrated

- Active Directory administration
- Windows Server administration
- Identity and access management
- Group Policy
- DNS
- Windows networking
- Virtual machine administration

## Lab Architecture

Domain Controller: DC01  
Client: PC01
